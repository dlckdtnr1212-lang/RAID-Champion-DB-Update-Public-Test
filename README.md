# RAID Champion DB — 자동 업데이트 공개 시험 저장소

> **안내: 이곳은 일반 사용자용 다운로드 페이지가 아닙니다.**  
> RAID Champion DB의 자동 업데이트 기능을 검증하기 위해 만든 공개 시험 저장소입니다.

## 프로그램을 다운로드하려는 분께

RAID Champion DB는 RAID: Shadow Legends를 위한 무료 Windows 챔피언 검색·팀 관리·데몬로드 전투 분석 프로그램입니다.

**최신 공식 베타: v1.0.0-beta.30.6 (Windows 10/11 64비트)**

- **[공식 프로그램 다운로드 페이지](https://github.com/dlckdtnr1212-lang/RAID-Champion-DB/releases/tag/v1.0.0-beta.30.6)**
- **[처음 설치할 때 필요한 Setup 파일](https://github.com/dlckdtnr1212-lang/RAID-Champion-DB/releases/download/v1.0.0-beta.30.6/JYrun.RAIDChampionDB-beta-Setup.exe)**
- **[메모장으로 읽는 쉬운 설치 안내](https://github.com/dlckdtnr1212-lang/RAID-Champion-DB/releases/download/v1.0.0-beta.30.6/READ_ME_FIRST_KO.txt)**

처음 설치하거나 기존 beta.29 ZIP 버전을 사용하던 분은 공식 페이지에서 **`JYrun.RAIDChampionDB-beta-Setup.exe` 하나만** 다운로드하세요. 이미 beta.30.6 설치형을 사용 중이라면 다시 설치할 필요 없이 프로그램에서 공개된 업데이트를 확인하시면 됩니다.

이 시험 저장소에 게시된 `.nupkg`, `.json` 등은 개발 중 검증을 위해 사용한 자료입니다. **일반 사용자는 이곳의 시험 파일을 다운로드하거나 실행하지 마세요.**

## 이 저장소의 목적

Windows 프로그램이 GitHub 로그인 없이 새 버전을 확인하고 다운로드한 뒤 교체·재실행하는지, 게임 데이터 업데이트가 적용되는지 확인하기 위해 만들었습니다.

- 시험 경로: beta.30.5 → beta.30.6
- 게임 데이터 시험: 1.0.0 → 1.0.1
- 게시된 시험 Release는 **실제 사용자용 최종 배포 파일이 아닙니다.**
- 공식 프로그램의 다운로드와 업데이트 배포는 별도의 [RAID Champion DB 공식 저장소](https://github.com/dlckdtnr1212-lang/RAID-Champion-DB)에서 관리합니다.

개발 및 검증 기록을 보존하기 위해 이 저장소를 유지하고 있습니다.
